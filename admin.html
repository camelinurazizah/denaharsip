Konfigurasi Cloud Backend & Database (Turso / Supabase)

Hubungkan aplikasi ke database Turso (libSQL/SQLite) atau Supabase (PostgreSQL), serta kelola sumber data aktif Gedung Kearsipan.

Pilih Database Aktif:
Memeriksa status koneksi database...
⚡ Kredensial Turso Database (libSQL / SQLite)
Dapat ditemukan di Turso Dashboard atau hasil perintah: turso db show [nama-db] --url
Dibuat via Turso Dashboard (Tokens) atau perintah: turso db tokens create [nama-db]
☁️ Kredensial Supabase Project
Dapat ditemukan di Supabase Dashboard -> Settings -> API -> Project URL
Dapat ditemukan di Supabase Dashboard -> Settings -> API -> Project API Keys (anon public)
